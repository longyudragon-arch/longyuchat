# AI 日报实施路线

## Phase 0：方案固定

本阶段目标：

- 固定技术路线
- 固定来源范围
- 固定 worker 与主站的边界
- 固定数据结构

当前状态：进行中

## Phase 1：最小可运行自动日报

目标：

- 支持 RSS / GitHub / Hacker News / Reddit 基础来源
- 跑通小时级扫描
- 跑通每日自动发布
- 主站可展示日报列表、详情、归档

交付标准：

- 每天至少可自动生成一期
- 网站首页可看到最新一期入口
- `/daily` 与 `/daily/[slug]` 可正常访问

## Phase 2：稳定性与质量增强

目标：

- 引入更好的去重与聚类
- 引入多模型 fallback
- 引入“低质量日不发”策略
- 增强来源白名单和优先级体系

交付标准：

- 相同事件的重复率显著下降
- 上游单个来源失败不影响整期日报
- 生成质量稳定

## Phase 3：扩展发布能力

目标：

- RSS 完整输出
- OG 图 / 分享图
- 可选邮件订阅
- 后台审计和重生成

交付标准：

- 可被 RSS 阅读器订阅
- 每期有稳定的分享预览
- 可以人工重发或重生成某一期

## 当前推荐优先级

先做：

1. 数据表
2. worker 输入输出
3. 自动发布流程
4. 前台页面

后做：

1. 更复杂来源
2. 更复杂推荐
3. 更复杂后台
4. 视觉增强
