# Import Order

推荐你在 Stitch 里按下面顺序导入：

1. 首页：`02-home`
2. 房间列表页：`03-rooms-list`
3. 聊天页：`04-chat`
4. 模型管理页：`05-models`
5. 新建房间页：`06-create-room`
6. 编辑房间页：`07-edit-room`
7. 登录页：`08-login`

每一页都建议一起提供：

1. 当前页面截图
2. `brief.md`
3. `code/` 目录中的文件
4. 必要时补充 [01-global](/C:/codeX/stitch_handoff/01-global) 里的全局文件

给 Stitch 的统一目标：

- 移动端优先
- 保持中文
- 提高可读性和层级清晰度
- 不改业务语义
- 不改后端契约
