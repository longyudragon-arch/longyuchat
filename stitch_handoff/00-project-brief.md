# Project Brief

这是一个面向中文用户的 AI 多模型聊天室前端项目。

产品目标：

- 配置多个模型
- 创建单聊或群聊房间
- 在群聊中让多个 AI 按顺序依次回复
- 保存聊天记录，并能回到历史房间继续聊天

本次交给 Stitch 的目标：

- 优化前端视觉层级
- 优化导航和卡片结构
- 优化移动端体验
- 保持中文产品感

不在本次范围内：

- 修改后端契约
- 新增 API
- 修改数据库结构
- 增加二期三期功能

硬性限制：

1. 不要改变“用户发消息后，AI 依次回答”的业务语义
2. 不要修改后端接口协议
3. 不要做脱离项目上下文的概念稿
4. 所有用户可见文案以中文为主
5. 优先可用性和移动端体验，而不是炫技
